> Minecraft 1.21.11（Fabric）纯客户端优化模组。版本：`1.1-beta1`。

Velox 只做一件事：**在不改变任何原版玩法的前提下，降低同一份行为所花的代价**。

- 不会改动生物 AI、目标选择、游戏规则等任何游戏逻辑；
- 不会改动网络包、不会拦截玩家行为；
- 所有优化都是客户端渲染/测量路径，结果与原版完全一致。

---

## 五档模式

配置写入 `config/velox.json`，切换即时生效、立即写盘，无需重进世界。

| 档位 | 中文 | 定位 |
|------|------|------|
| `vanilla` | 原版 | 全部关闭，表现与未安装本模组完全一致 |
| `safe` | 安全 | 只开最稳妥的客户端优化（物品/经验球剔除 + 粒子限流 + 保守距离） |
| `eco` | 节能 | 偏向省内存省电，距离更紧、预算更低 |
| `aggressive` | 激进 | 能开的全开、距离拉满，允许牺牲部分画面细节 |
| `auto` | 自动 | 动态调配（见下） |

> ⚠️ 出于「绝不改变原版玩法」的硬性要求，所有 **tick 类游戏逻辑优化**（生物 AI 节流、目标选择器跳过）在 v1.1 起**永久禁用**，绝不注入。Velox 因此是一个纯客户端渲染优化模组。

---

## Auto 档（动态调配）

Auto 档以 Safe 档为基准起步，另起一个后台线程，依据**客户端可观测指标**持续微调：

- **FPS / 帧生成时间**：低于目标 ×0.9 持续约 3 秒 → 收紧剔除距离与粒子预算；
  高于目标 ×1.05 持续约 6 秒 → 放宽。带**滞回 + 小步长**，避免反复横跳。
- **内存 / CPU**：每 5 秒采样一次，资源紧张时额外收紧粒子预算。
- **GPU 负载**：纯 Java / Minecraft 下没有跨平台可靠获取方式（需 OpenGL timer query 或
  NVML 本地库，引入开销与兼容性风险），故不纳入，改用 CPU / 内存近似。

所有调整只动「剔除距离」「粒子数」这类渲染预算，绝不触碰游戏逻辑。

## 切换方式（界面与指令同步）

### 游戏内界面（Mod Menu）
1. 安装 [Mod Menu](https://modrinth.com/mod/modmenu)；
2. 主菜单 → 模组 → 选中 **Velox** → 配置；
3. 界面只有一个选项：**性能模式**，点击在五档之间循环切换；
4. 界面同时显示「原版设置跟随」状态，并提供「恢复跟随档位」入口。

### 指令
```
/velox auto | safe | eco | aggressive | vanilla
```
- 支持 Tab 补全；输错会提示可用档位；
- 执行后反馈「切到哪个模式、是否立即生效」；
- 指令与界面共用同一份状态：**指令切成 Eco，打开界面必显示 Eco**。

## 联机安全

- Velox 是纯客户端优化，**单人 / 多人都能生效**，不改动任何网络包；
- 联机时若进入远程服务器，模组会自动强制关闭任何可能改变玩法的优化（当前即全部 tick
  类逻辑优化，已永久禁用，零风险）；
- 保留的剔除 / 粒子 / 帧率 / 图形设置均为客户端渲染，不影响联机一致性。

---

## 原版设置跟随（自定义状态）

Velox 会监听你在原版视频设置里的手动改动：

- 改过某项（视距、模拟距离、粒子、云、帧率上限、垂直同步、图形画质、实体阴影等）→
  界面显示「自定义（实际值）」；
- **Velox 只展示、不反向覆盖**，你手动改的值永远保留；
- 点「恢复跟随档位」→ 把这些项改回当前档位的预设值，并清除自定义标记。

## 内存看门狗

一个诊断线程，周期性打印堆使用（不调用 `System.gc()`、不私自驱逐缓存）。
内存持续高于 90% 时给出告警，帮助你正确设置 `-Xmx`。
